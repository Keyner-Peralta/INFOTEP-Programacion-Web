# Repositorio del Curso de Programación Web - INFOTEP

Este repositorio contiene todos los trabajos, prácticas, ejercicios y apuntes realizados durante mi participación en el curso de **Programación Web** impartido por INFOTEP. El curso está dividido en nueve módulos, cada uno enfocado en desarrollar habilidades esenciales en el desarrollo web, desde fundamentos matemáticos hasta programación backend con ASP.NET.

## Contenido por módulos:

- **Módulo 1 - Matemática Discreta**  
  Fundamentos lógicos y matemáticos aplicados a la informática, esenciales para la resolución de problemas y diseño de algoritmos.

- **Módulo 2 - Diseño de Estructura de una Página Web**  
  Principios básicos de diseño web, estructura de HTML y buenas prácticas de maquetación.

- **Módulo 3 - Introducción al CSS**  
  Fundamentos de hojas de estilo en cascada (CSS) para aplicar estilos, colores, tipografía y diseño responsivo en páginas web.

- **Módulo 4 - JavaScript**  
  Programación del lado del cliente para añadir interactividad a las páginas web, manejo del DOM y eventos.

- **Módulo 5 - Estructura de Datos y Algoritmos**  
  Implementación de estructuras como listas, pilas, colas y árboles, junto con algoritmos de ordenamiento y búsqueda.

- **Módulo 6 - Bases de Datos**  
  Diseño y gestión de bases de datos relacionales, modelado entidad-relación y lenguaje SQL.

- **Módulo 7 - Programación PHP**  
  Desarrollo de aplicaciones dinámicas del lado del servidor utilizando PHP, manejo de formularios, sesiones y conexión a bases de datos.

- **Módulo 8 - Programación Orientada a Objetos**  
  Conceptos fundamentales como clases, objetos, herencia, polimorfismo y encapsulamiento aplicados en el desarrollo web.

- **Módulo 9 - ASP.NET**  
  Creación de aplicaciones web robustas utilizando el framework ASP.NET, integrando diseño frontend con lógica backend en .NET.
